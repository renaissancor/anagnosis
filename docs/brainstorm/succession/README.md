# Succession redesign — brainstorm

> **Status: BRAINSTORM, not canonical.** The live, implemented model is still the A/B/C/D matrix documented in [`docs/model/succession.md`](../../model/succession.md) and generated by `code/generate-successions.js`. Nothing here is built yet. Promote to `docs/model/` only after the design is ratified and a generator + curated tables exist.
>
> **Provenance:** design session 2026-06-21. Captures the reasoning so it survives a context reset.

## Thesis

Succession — *inheritance between polities* — is the **load-bearing spine of Anagnosis**, not the civilization tier ([civilization is deferred](../../model/civilization.md)). The current succession model is too thin to carry that weight, and it's the wrong *kind* of thing (derived similarity, not curated judgment). This directory specs the replacement.

## The one-sentence redesign

Stop modelling succession as **one blended similarity edge per polity-pair**; model it as a **set of curated, per-axis inheritance claims**, each `(successor ← source, axis, stance, mechanism, topology)`, with **recognition as a separate perspectival relation**.

## Key decisions reached this session

1. **Succession type = Topology × Mode**, a small product space — not an ever-growing alphabet (A, B, C, D, E…). See [`02-type-system.md`](./02-type-system.md).
2. **Inheritance is per-axis and multi-parent.** One successor inherits different axes from *different* sources (the Ottoman inherits territory from Byzantium, the caliphate from the Abbasids, its dynasty from the Seljuks). See [`03-data-model.md`](./03-data-model.md).
3. **`dynastic_change` is NOT a succession.** If only the ruling house changed, the polity persists → it's a `polity_dynasty` row, not a succession edge.
4. **The new layer is curated, not derived.** Mechanism, legitimacy, and recognition are historical judgments a script cannot compute. The old generator is demoted to an *evidence / candidate suggester*. See [`01-why-redesign.md`](./01-why-redesign.md).
5. **Recognition is perspectival** — `recognized_by(claim, observer) → degree`, not a boolean. This is the same "don't collapse the perspectives, index them" move that resolved the civilization tier.
6. **Polity-split = where an edge lands** ([`07-polity-split.md`](./07-polity-split.md)). Split on foundational *ideology* change (≠ religion) or a *sovereignty* event; an interruption splits only if the polity was *extinguished* (revival), not merely *suspended* (continuation). The split question and the succession question are the same question.
